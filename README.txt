ELEGANTWEB — Starter Website

FILES
- index.html: the website page to upload to GitHub.

HOW TO PUBLISH WITH GITHUB PAGES
1. Open your GitHub repository named elegantweb.
2. Choose Add file > Upload files.
3. Upload index.html.
4. Tap Commit changes.
5. In the repository, open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Choose branch main and folder /(root), then Save.
8. Wait a few minutes for the published site link to appear.

NOTE
This starter website has working browser-based tools such as the prompt builder and profit calculator. It does not yet include a live AI detection engine, user accounts, or online payments.
